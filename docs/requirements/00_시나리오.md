1. 시나리오 이름

실내 방문자 안내 및 이동 중 환경 점검 로봇

2. 서비스 목적

처음 방문한 실내 공간(강의실·복도·전시 구역)에서 방문자가 목적지를 찾지 못해 발생하는 문제를 해결한다. 로봇이 방문자를 지정된 목적지(class1~meeting)까지 직접 안내하고, 이동 경로상 각 지점의 온도·습도·조도 등 환경 상태를 함께 점검하여 이상 여부를 기록·안내한다.

3. 주요 사용자

- 방문자: 목적지를 모르는 외부인 또는 신규 방문객

- 관리자: 목적지·경로를 사전 등록하고 로봇 상태를 원격으로 확인하는 담당자

4. 서비스 장소

강의실 및 인접 복도 등 실측 가능한 실내 공간. 지정 목적지 8곳(class1~meeting) 및 충전 스테이션 1곳을 포함한다. 발표 당일 동일 공간에서 반복 재현 가능해야 한다.

5. 사전 조건

- SLAM으로 작성한 지도(원본·편집본)가 로봇에 등록되어 있다.

- 목적지 class1~meeting의 좌표와 각 위치의 ArUco 마커 ID가 사전 등록되어 있다.

- 로봇 배터리가 90% 이상 충전된 상태다.

- 로봇의 초기 위치는 충전 스테이션 앞 정렬점으로 알려져 있다.

6. 시작 조건

- 전원 인가 후 PM2가 필요한 노드(bringup, navigation, sensor_bridge, camera, aruco, voice, service_manager, status)를 자동 실행하고, 30초 이내 전체 노드가 active 상태가 된다.

- AMCL 기반 초기 위치 설정이 완료된다.

- 사용자가 로봇 디스플레이 또는 원격 GUI에서 목적지(class1~meeting)를 선택하고 시작 버튼을 누른다.

7. 정상 동작 순서

- 로봇 전원이 켜지면 웰컴 라이트 LED가 웨이브 점등 애니메이션을 재생하고 로봇 눈이 눈뜨기 표정을 보여주며, PM2가 필요한 ROS 2 노드를 자동 실행한다.

- 로봇의 초기 위치를 충전 스테이션 앞 정렬점으로 설정한다.

- 목적지 선택 전 대기 상태에서는 로봇 디스플레이에 목적지(class1~meeting) 선택 메뉴 화면을 표시한다.

- 사용자가 GUI 또는 로봇 디스플레이에서 목적지(class1~meeting)를 선택한다.

- 로봇이 음성으로 "안내를 시작합니다"를 출력하고 로봇 눈을 이동 표정(진행 방향을 향한 눈동자 애니메이션)으로 전환한다.

- 등록된 경유점(10개 이상)을 순서대로 이동한다.

- 각 경유점에서 DHT11 온습도 센서와 조도 센서 값을 측정하여 위치·시간과 함께 저장한다.

- 후진이 필요한 구간에서는 IR 센서로 후방 20cm 이내 장애물 여부를 확인한다.

- 목적지 도착 시 카메라로 ArUco 마커를 인식해 마커 ID로 목적지를 확인하고, 목표점 3cm 이내에 정지한다.

- 카메라로 도착 인증샷을 촬영하여 GUI에 업로드하고, 디스플레이에 도착 안내 문구를 표시하며 음성으로 "목적지에 도착했습니다"를 출력한다.

- 5초 대기 후 시작 위치를 향해 복귀 경로로 이동한다.

- 충전 스테이션 앞 대기점으로 이동한 뒤 ArUco 마커로 정렬하여 저속 접근 후 도킹을 완료한다.

- 음성으로 "임무를 완료했습니다"를 출력하고 로봇 눈을 웃는 표정으로 전환한다.

| 파킹 실패 | 도킹 시도 3회 실패 | 정지 상태 유지 및 스피커 음성으로 파킹 실패를 안내, 관리자에게도 알림. 배터리 40% 이하 도달 시 정지를 우선 |
| 사용자 임무 취소 | GUI 취소 버튼 또는 물리 버튼 입력 | 즉시 정지 후 안전 위치 대기, 음성 "임무를 취소합니다" 출력 |
| 긴급 정지 버튼 | 버튼 입력 | 0.5초 이내 모터 전원 하드웨어 차단, 해제 전까지 모든 이동 명령 무시. 임무 재개는 중단 지점을 알 수 없어 자동 이어하기 대신 시스템 리부팅으로 처리하며, 리부팅 전까지는 teleop+servo 기반 수동 제어로 로봇을 안전한 위치까지 이동 가능 |
| ROS 2 노드 비정상 종료 | 노드 프로세스 종료 감지 | PM2가 즉시 재시작 최대 3회 시도, 실패 시 안전 정지 상태 유지 및 로그 기록 |

10. 사용 센서

| **센서** | **구분** | **서비스 내 판단 용도** |
| --- | --- | --- |
| IR 장애물 센서 | 입력 | 후진 중 20cm 이내 장애물 감지 시 즉시 정지 |
| 푸시버튼 | 입력 | 임무 시작, 길게 누르면 긴급정지 |
| 터치 센서 | 입력 | 터치 시 지정된 위치로 이동 명령을 트리거 |
| DHT11 온습도 센서 | 입력 | 경유점별 환경 측정, 온도 30도 이상 시 이상 알림 |
| 조도 센서 | 입력 | 경유점 밝기 측정, 기준치 이하 시 저조도 구역으로 기록 |
| 3.5인치 LCD (로봇 눈) | 출력 | 보조 아두이노로 구동, 상태별 눈 표정으로 대기·주행·도착·장애물·오류·충전 상태를 표현 |
| 웰컴 라이트 LED | 출력 | 동일 보조 아두이노로 구동, 전원 ON/OFF 시 웨이브 점등·페이드아웃 애니메이션 재생 |
| 2D LiDAR | 입력(기본 장착) | 전방 장애물 감지 및 회피, 위치 추정 |
| 휠 엔코더 | 입력(기본 장착) | 오도메트리 계산 |

로봇 눈(LCD)과 웰컴 라이트(LED)는 메인 시스템(라즈베리파이/OpenCR)과 별도인 보조 아두이노 1대가 함께 구동한다. 라즈베리파이가 UART로 현재 상태 값만 전달하면 보조 아두이노가 표정·조명 출력을 전담하므로, 메인 시스템 부하나 오류와 무관하게 항상 즉각적으로 반응하며 주행·안전 기능에는 영향을 주지 않는다.

11. 카메라와 ArUco 활용 방법

- 목적지 확인: 각 목적지(class1~meeting) 앞에 고유 ID의 ArUco 마커를 부착(2026-08-05 이후 도킹 마커 1개만 실제 사용, 목적지 마커는 좌표 기반 판정으로 대체됨 - 위 노트 참고)하고, 도착 시 마커 ID로 목적지를 검증한다.

- 정밀 파킹: 충전 스테이션의 ArUco 마커를 이용해 마커 중심과 로봇 중심의 좌우 오차 및 거리 오차를 계산하고, 오차를 줄이며 저속으로 접근한다.

- 추가 카메라 응용: 목적지 앞 사람 존재 여부를 확인하여 사람이 있으면 "안내 중입니다" 음성 안내 후 대기한다.

12. 경유점과 Trajectory 구성

경유점 10개 이상: 출발점(충전 스테이션), WP1~WP6(복도 분기점), 목적지(class1~meeting), 충전 대기점, 정렬점, 도킹점.

Trajectory 1 — 안내 경로

출발점 → WP1 → WP2 → WP3 → WP4 → 목적지(class1~meeting 중 선택)

Trajectory 2 — 복귀·충전 경로

목적지 → WP5 → WP6 → 충전 대기점 → 정렬점 → 도킹점

13. 음성·효과음·로봇 눈 표정

아래 상태 전환 시점마다 음성·효과음과 로봇 눈(3.5인치 LCD) 표정을 함께 출력한다. 음성은 주행 제어 지연을 막기 위해 별도 노드에서 처리하고, 로봇 눈은 보조 아두이노가 라즈베리파이로부터 UART로 상태 값을 받아 독립적으로 표시한다. 기본적으로 이동 중에는 로봇 눈 표정 화면을, 정지 상태(대기·오류·일시정지 등)에서는 상태 확인용 인터페이스(메뉴·상태 정보) 화면을 표시하는 것을 원칙으로 한다.

| **상태** | **음성·효과음** | **로봇 눈 표정** |
| --- | --- | --- |
| 대기 상태(목적지 미선택) | 없음 | 디스플레이에 목적지 선택 메뉴 화면 표시(눈 표정 대신 메뉴 UI 노출) |
| 시스템 시작 | 시작음 + "시스템을 시작합니다" | 눈뜨기 애니메이션 |
| 주행 준비 완료 | "주행 준비가 완료되었습니다" | 정면을 응시하는 기본 눈 |
| 임무 시작 | "안내를 시작합니다" | 진행 방향을 향한 눈동자 이동 애니메이션 |
| 목표점 도착 | "목적지에 도착했습니다" | 웃는 눈(초승달 모양) |
| 장애물 발견 | 경고음 + "장애물이 감지되었습니다" | 동그랗게 커진 놀란 눈 |
| 임무 일시 정지 | "임무를 일시 정지합니다" | 반쯤 감긴 눈 |
| 통신 끊김 | "통신이 끊어졌습니다. 임무는 계속 진행됩니다" | 눈 옆 Wi-Fi 아이콘 점멸 |
| 충전 위치 도착 | "충전 위치에 도착했습니다" | 배터리 아이콘 표시 |
| 임무 완료 | 완료음 + "임무를 완료했습니다" | 웃는 눈 + 반짝임 효과 |
| 오류 발생 | 경고음 + "오류가 발생했습니다" | 빨간색 X자 눈 |

웰컴 라이트 (전원 ON/OFF)

차량의 웰컴 라이트처럼, 로봇 전원 스위치 상태에 맞춰 별도 LED가 점등·소등 애니메이션을 재생한다. 로봇 눈과 동일한 보조 아두이노가 담당하며 라즈베리파이·OpenCR 동작 여부와 무관하게 전원 라인 상태만으로 독립 동작한다.

| **전원 상태** | **웰컴 라이트 동작** |
| --- | --- |
| 전원 ON | 앞뒤 LED가 순차적으로 밝아지는 웨이브 애니메이션(약 2초) 후 대기 밝기(30%)로 유지 |
| 전원 OFF (시스템 종료) | 대기 밝기에서 서서히 어두워지는 페이드아웃 애니메이션(약 1.5초) 후 완전 소등 |

15. 안전 기능

- 하드웨어 긴급정지 버튼: 소프트웨어 상태와 무관하게 0.5초 이내 모터 전원을 차단한다.

- 전방 장애물: LiDAR 기준 30cm 이내에서 감속, 20cm 이내에서 정지한다.

- 후방 장애물: 후진 중 IR 센서 기준 20cm 이내에서 즉시 정지한다.

- 배터리 관리: 40% 이하 도달 시 경고음으로 사용자에게 알리고, 20% 이하 도달 시 진행 중인 임무를 중단하고 충전 스테이션 복귀를 우선한다.

- 위 안전 기능은 Wi-Fi 연결 여부와 무관하게 로봇 내부에서 독립적으로 동작한다.
